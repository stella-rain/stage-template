# Stella Rain stage repo

Template for publishing your own **Stella Rain** stages. The game creates a repo from this
template the first time you publish, so you normally never need to touch git.

- Stages live in `stages/` as `<stage-id>.json` with a matching `<stage-id>.replay`.
- Each published version is a tag named `<stage-id>@v<N>`, for example `frost-cavern@v1`.
- The `stella-rain-stage` repository topic makes your stages discoverable in the game.
